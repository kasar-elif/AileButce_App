# AileBütçe – Family Budget Management App

## About the Project

AileBütçe is a family budget management web application developed to help families track their income, expenses, monthly budgets, and savings goals in one place.

The application provides a simple and user-friendly interface where users can monitor their financial situation and manage their household budget.

## Features

- Dashboard displaying total income, expenses, and balance.
- Add, edit, and delete income and expense transactions.
- Search and filter transactions by type and month.
- Set monthly spending limits for different categories.
- Track category-based spending and receive overspending warnings.
- Create savings goals and add contributions.
- Store application data using LocalStorage.
- Responsive interface for desktop and mobile devices.

## Technologies Used

- React
- Vite
- JavaScript
- HTML
- CSS
- LocalStorage

## Installation and Running

1. Clone the repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd AileButce
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL displayed in the terminal.

## Data Storage

The application uses the browser's LocalStorage to save transactions, monthly budget limits, and savings goals.

Data is stored locally in the browser and is not synchronized between different devices or browsers.
